# Conclusion
After following the sections from this lesson for `nano`, `Vim`, and `Emacs`, you should hopefully be able to:

* Open a file

* Edit a file

* Save a file

* Search for text within a file

* Exit the text editor (with or without saving)

This tutorial does not go into great depth to describe any of the three text editors mentioned. If you're wanting to use any of the text editors frequently (which we do not advise unless you are frequently working remotely) we recommended that you find a textbook that goes into extensive detail about all of your editors available features.
