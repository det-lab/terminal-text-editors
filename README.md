# Terminal Text-Editors
This lesson introduces the basics of using text-editors in terminal environments, including opening, editing, saving, closing, and searching for text within files. These operations are discussed for the three most popular text-editors of nano, Vim, and Emacs.
# Lesson Outline
## Introduction (`index.md`)
A brief overview of the lesson and its contents.
## Nano (`01_nano.md`)
Describing the basic commands and benefits of the nano text-editor.
## Vim (`02_vim.md`)
Describing the basic commands and benefits of the vim text-editor.
## Emacs (`03_emacs.md`)
Describing the basic commands and benefits of the Emacs text-editor.
